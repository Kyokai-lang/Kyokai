# Administered Members

This file is the public roster of administered project members for Kyokai.

## Membership Process

Membership is granted and revoked solely by the lead maintainer. This file is the public record of that status.

### Lead Maintainer

### What Administered Members Can Do
- Ack final shape wordings on proposals (3 acks are required for an accepted proposal to become a decided D-point).
- Write accepted shape into `kyokaidecided.md` (which assigns the D-point number).
- Write spec prose based on accepted decisions.
- Perform code and PR review.

### What Only The Lead Maintainer Can Do
- `Lead YES`: Bypass the 3-ack gate to accept a proposal immediately.
- Grant or revoke administered membership.
- Final wording quality control.
